_A loop that rewinds to the root cause

Six phases, each with its own agent and its own artifact. The testing phase has two independent lanes running concurrently. A defect does not go back to whoever reported it — it goes back to the phase that created it.

Why two lanes at once

A second pass launched after the first can read its report — and stops being a second opinion. Launched concurrently, there is nothing to peek at: no report exists yet. Independence stops being a rule somebody has to enforce.

Collisions ruled out structurally

Each lane writes its own artifact, its own test file and its own inbox, numbering from a disjoint ID block. Neither touches findings.jsonl. The orchestrator merges — a defect found by both gets confirmed_by.

When the loop gives up

6 iterations, 3 revisions inside an agent. The same finding code three times in a row → blocked. The same case with two different results across the lanes, too → that is not a defect to route, just two different states.
